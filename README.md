# KSPSS

> ⚠️ **This project is currently experimental and not ready for gameplay use. Expect bugs, crashes, and incomplete features.**

**Kerbal Space Program Super Sampling**

## Goal

KSPSS aims to bring modern super-resolution technologies to Kerbal Space Program 1.

## Planned Features

- Render diagnostics
- DLSS Super Resolution
- DLAA
- XeSS (planned)
- AMD FSR (planned)

## Current Status

- [x] Repository created
- [x] Initial render probe
- [ ] Stage 1 validation
- [ ] Render redirect
- [ ] Experimental DLSS
- [ ] Functioning DLSS
- [ ] AMD FSR
- [ ] Intel XeSS

       
## Future Projects

If KSPSS proves successful, I plan to build additional graphics technologies on top of its rendering framework.

One planned project is **KSPFG (Kerbal Space Program Frame Generation)**, which would reuse KSPSS's rendering infrastructure instead of duplicating it. This modular approach should make future rendering features easier to maintain and extend.

*This project is currently only a long-term goal and is not part of the initial KSPSS release.*

---

## Disclaimer

KSPSS is an experimental research project.

The current focus is validating Kerbal Space Program's rendering pipeline before attempting to integrate modern upscaling technologies. Features listed above represent project goals and may change as development progresses.
